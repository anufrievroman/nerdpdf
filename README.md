# nerdpdf

Minimal keyboard-driven PDF viewer (PyMuPDF + Qt/PySide6).

## Install / run

    python3 -m venv .venv
    .venv/bin/pip install -e .
    .venv/bin/nerdpdf file.pdf        # or: .venv/bin/python -m nerdpdf file.pdf
    .venv/bin/nerdpdf -h              # options and keys
    .venv/bin/nerdpdf -v              # version

### macOS app

    .venv/bin/nerdpdf --install-app                  # -> ~/Applications/nerdpdf.app
    .venv/bin/nerdpdf --install-app /Applications

The bundle runs this checkout's `.venv`, so it picks up code changes without reinstalling;
reinstall only if the venv is moved or recreated. It shows up in Spotlight, the Dock and
Finder's "Open With" for PDFs.

## Keys

| Key | Action |
| --- | --- |
| `j` / `k` (↓ / ↑) | scroll down / up |
| `h` / `l` (← / →) | scroll left / right |
| `J` / `K`, `n` / `p` | next / previous page (`n` steps through matches while a search is open) |
| `Space` / `Backspace` (`Shift+Space`) | next / previous page |
| PgDn / PgUp | scroll one screen |
| `gg` / `G` | first / last page; `12G` or `12gg` goes to page 12 |
| `a` / `s` | fit width / fit page |
| `d` | toggle single-page mode (one page on screen) / continuous feed |
| `=` / `-` | zoom in / out |
| middle-button drag | pan the document |
| Shift+wheel, Cmd/Ctrl+wheel, pinch | zoom at the cursor |
| `/` | search: Enter finds, then `n` / `N` = next / previous match, Esc = close |
| `f` / `F` | toggle fullscreen; `Esc` leaves it (after closing search, if open) |
| `o` | open file (drag & drop works too) |
| `q` | quit |

Slide decks (first page 4:3, 16:10 or 16:9 landscape) open in single-page mode, fitted to
the page, without changing the zoom remembered for regular documents. In single-page mode
the wheel flips pages once you scroll past the page edge.

Counts work like vim: `5j`, `3J`.

Zoom / fit mode, window geometry and the last position in each file are remembered
(QSettings). Background follows the system light/dark theme.

The icon is generated by `tools/make_icon.py` (writes `nerdpdf/icons/`).
